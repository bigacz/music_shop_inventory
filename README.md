# Music Shop Inventory

Inventory management app for storing items.
**[Live preview](https://music-shop-inventory.onrender.com)**

## Features

- MVC project structure.
- Inventory data stored in PostgreSQL database.
- REST API endpoints.
- Database setup script
- Views for editing adding and displaying items, categories and producers.

## Getting started

```sh
git clone git@github.com:bigacz/music_shop_inventory.git
npm install
npm run dev
```
